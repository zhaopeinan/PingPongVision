# 球台标定与跨区板数设计

## 目标

将板数从“轨迹折返点数量”改为“球完成一次球台半区跨越的次数”，并使用得分间隔将连续视频分成内部得分段。界面不再展示“回合”概念，只保留板数和球速等实时信息；内部仍保留得分段对象，用于统计、筛选和导出剪辑。

## 用户流程

1. 用户选择视频后，在球台标定入口选择一帧代表性画面。
2. 用户按顺序点击球台四角：左上、右上、右下、左下。
3. 系统校验四点是否有限、顺序正确且不退化，生成透视变换。
4. 系统将球台映射到标准坐标 `[0, 1] x [0, 1]`，以 `x=0.5` 作为中网/球台中线。
5. 中网两点标定为可选校正：用户可以点击中网两端；未提供时直接使用透视后的 `x=0.5`。
6. 标定结果按视频保存，并在开始追踪或离线分析时自动加载。

标定失败时不启动跨区板数模式，并提示用户重新标定；旧视频没有标定数据时暂时使用未标定的画面中线作为兼容回退，但结果应标注为低可信。

## 板数规则

- 球坐标先经过球台透视变换；未标定时使用原图坐标归一化。
- 只关心球台的左右半区，不绑定选手身份。球从左半区进入右半区，板数加 1；之后从右半区进入左半区，板数再加 1。
- 采用中线迟滞区，避免球在 `x=0.5` 附近抖动重复计数：例如进入 `x >= 0.55` 才确认右侧，进入 `x <= 0.45` 才确认左侧。
- 必须先确认球在一侧，再确认进入另一侧，才能产生一次跨区事件。
- 连续超过 2 秒没有产生新的跨区事件，结束当前内部得分段并重置当前板数和跨区状态。
- 球短暂丢失不立即结束得分段；只要丢失时间不超过 2 秒，后续重新检测到球仍可继续计数。
- 第一侧位置只用于建立方向状态，不直接增加板数；如果视频从球台中间开始，则等待球首次完成跨区后计数。

## 组件设计

### TableGeometry

扩展现有四角透视变换能力，支持从视频级标定数据创建几何对象，并提供：

- 图像坐标到标准球台坐标的转换。
- 可选中网两点校正数据的保存与读取。
- 标定有效性校验。

中网两点只作为校正信息保存；默认情况下由四角透视结果推导 `x=0.5`，不改变球台标准坐标的定义。

### 标定存储与 API

按 `video_id` 保存标定数据，字段包括：

- `frame_index`
- `corners`: 四角坐标，固定顺序为左上、右上、右下、左下
- `net_points`: 可选的中网两点
- `version`

增加读取、保存和删除接口。保存前校验视频存在、帧号有效、四角格式正确；删除后恢复未标定状态。

### 标定画布

复用现有可缩放、可拖动的标注画布：

- 增加 `table` 标定模式和 `net` 标定模式。
- 四角点击完成后显示透视后的球台中线预览。
- 中网模式最多接受两个点，并允许清除重选。
- 保存前显示四角顺序和标定状态，避免误把视频外物体当作球台角点。

### BallCrossingCounter

新增独立的跨区计数器，输入每帧的球台归一化 `x`、帧号和时间戳，输出：

- 当前板数
- 当前得分段状态
- 新产生的跨区事件
- 得分段结束事件

计数器不依赖 YOLO、MediaPipe 或选手身份，也不依赖轨迹折返点。它由 `RallyDetector`/视频分析管线调用，实时追踪和离线分析共用同一逻辑。

### UI

- 删除实时指标中的“回合”。
- 保留“板数”和“球速”。
- 回合列表内部可以继续存在，但用户可见文案改为“得分段”或“高板数片段”，避免把内部状态误解成独立识别出的比赛回合。
- 每个得分段显示板数、时间范围和球速信息。

## 数据流

```text
视频帧
  -> TrackNet 球坐标
  -> TableGeometry 透视变换
  -> BallCrossingCounter 判断左右半区跨越
  -> 得分段状态机（2 秒无跨区则结束）
  -> 板数、球速、剪辑结果
```

实时追踪和离线分析必须共享 `BallCrossingCounter`，避免实时显示和最终剪辑使用不同板数算法。

## 异常与兼容

- TrackNet 未检测到球时不增加板数；连续 2 秒无跨区才结束当前得分段。
- 球检测在中线迟滞区来回抖动时不重复计数。
- 四角退化、点序错误或中网点数不为 0/2 时拒绝保存。
- 没有标定数据的旧视频兼容画面中线，但在状态提示中标记“未标定”。
- 标定数据与 TrackNet 模型选择相互独立，切换模型不会覆盖标定。

## 验证方案

- `TableGeometry`：验证四角映射到标准坐标、退化四边形拒绝、可选中网数据序列化。
- `BallCrossingCounter`：验证左到右和右到左各加 1、中线迟滞不重复计数、2 秒超时清零、球丢失恢复。
- API：验证标定数据按视频保存/读取/删除和非法输入拒绝。
- 实时元数据：验证只返回板数和球速展示所需字段，内部得分段计数与离线结果一致。
- 前端：验证标定模式切换、画布坐标转换、保存后重新打开仍显示标定点。
